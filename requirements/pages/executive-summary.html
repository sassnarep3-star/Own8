The four decisions that actually need making

  1. What counts as winning? Until that is written down, no leaderboard can award anything. See suggestion SG-01.
  2. May a non-official price ever enter the project? Without one, everything stays descriptive. See SG-04 and flag REQ-F-09.
  3. Is the depth-chart half of the availability requirement in scope? It is only achievable postgame, from game books. See SG-03.
  4. Which of the nine published surfaces is the site? See SG-07 and flag REQ-F-08.

What this session did not do

No player prop was originated, because a per-player game log does not exist and inventing one would break the rule. No parlay was priced, because no leg correlation can be measured without event-aligned data. No injury weighting was applied, because the NFL publishes designations without probabilities. No award was made, because nothing passed a gate. No inherited file was edited; findings about inherited files are published as review flags.

Research boundary

Every number on this page is either an official value, or this project's arithmetic on official values, and each row links the official page it came from. The project makes no claim of an edge, no profitability claim, and no claim that luck has been removed. Nothing here is betting advice.
