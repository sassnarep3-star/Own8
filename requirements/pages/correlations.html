Reading these correctly

Correlation is not causation and not prediction. A team-level association between passing volume and game total tells you something about how games unfold; it does not tell you whether two specific legs in one game move together. Assuming independence, rho = 0, is a claim that must be justified, and the safe default is not to assume it.

What survives, plainly

Nothing here survives a family-wise correction comfortably. The one raw p-value below 0.05 is the same-game side-versus-total residual, and it does not survive Holm across the family. The practical consequence is that this project has no measured dependence it can defend, so no combination can be priced from it. That is a finding, not a gap in effort.
