Decision support

Measured evidence, reviewable suggestions and open questions — built so a choice can be made before anything is implemented.

The one result that matters

On all 15 completed Week 9 games the site's own frozen lines picked 13 winners (86.7%). Against a coin flip that looks significant (p=0.007). It is not evidence of skill: an identical 86.7% is achieved by simply picking the team with the better season point differential, and 92.3% by picking the better record. The model adds nothing measurable on this slate.

What this section is for

This is the decision layer: the evidence that was actually measured, the suggestions that need a choice, and the questions that must be answered before anything is implemented. Nothing on these pages has been applied to the live dashboard.

Where to go

  • Week 9 test — the frozen lines scored against official results, with naive baselines. Supports the decision: does the current method show any skill?
  • Suggestions — six proposals, each with options, cost, risk and a recommendation. Supports the decision: which path to implement, if any.
  • Open questions — what is answered, what is still open, and what has to happen to answer it.
  • Injuries and depth — official Week 10 availability, plus proof that starting-lineup depth is not published by the NFL.
  • Anti-luck rules — how to stop luck being rewarded, and what the current leaderboard design gets wrong.
  • Flagged for review — irregularities and blanks, each with the source that shows the problem.

How to use it

Read the Week 9 test first — it changes how every other number on the site should be read. Then open Suggestions, pick an option per item, and record the choice. The questions page lists what is still blocked, so a choice is only made once its blockers are answered.

Verification rule used throughout

Every table row links an official source. Where an official source does not publish a value, the cell is blank (shown as —) and the item is flagged. No value on these pages was inferred, estimated or carried over from a non-official source.
