Validation Framework

Validation Gates

Every strategy must pass ALL six gates before a signal is released. One blank or failed gate = PAUSED. No exceptions. This is how luck is removed: only verified, skill-based inputs generate signals.

GateWhat it requiresVerified?Source
V1 Official-data completeness Every strategy input traced to an official source link; each table row on this site carries its source. PARTIAL — team data verified (NFL.com); player data flagged UNVERIFIED (Next Gen Stats totals vs games played mismatch) nfl.com/standings • nextgenstats.nfl.com
V2 Sample size Minimum N observations computed from verified data before a strategy can qualify. BLANK — UNVERIFIED. Game-by-game history is not available from the official sources used; season aggregates only. Flagged for Review: F-02
V3 Correlation limit For multi-leg strategies, |Pearson r| between legs ≤ 0.45 unless the correlation is explicitly documented and the play is sized down. Same-game legs require documented correlation. Documented where computable (see Correlations page). Same-game rho unknown for P-02 → blocked. Correlations • data/correlations.md
V4 Edge vs implied line Modeled probability minus implied probability from the betting line. Positive edge required to release. BLANK — UNVERIFIED. NFL.com does not publish betting lines, spreads, totals, or implied probabilities (sportsbook data). Flagged for Review: F-04
V5 Backtest pass rate Historical win rate of the strategy over verified historical games. BLANK — UNVERIFIED. Historical game-by-game results unavailable from the official sources used. Flagged for Review: F-05
V6 Availability / injury check All key players active per the official NFL injury report before release. BLANK — UNVERIFIED. Injury report not fetched in this session. Flagged for Review: F-06
