The answer to the requirement, stated plainly

The requirement is to know when a 2nd, 3rd or 4th string player replaces a starter. That is not knowable before kickoff from any official source: the depth-chart URL returns 404 and no other official page ranks backups. It IS knowable after the game from the official Game Book, which prints who actually started in each slot. So the repository measures replacement as a change against a previous official listing, and refuses to publish a pregame string ordinal it cannot source.
