Verification standard applied

  • Every table row on this site carries a source link to an official site.
  • If a value cannot be confirmed from an official source, it is left blank and flagged UNVERIFIED (above).
  • No values are inferred or filled in.
  • Standings data (32 teams) was verified cell-by-cell against the official NFL.com standings page.
  • Correlations were computed from the verified exports; computation is documented in data/correlations.md (repository) with the script used.
