# injury-depth/ — Week 10 official injury report tracker (session d6bada32)

- `data/w10_transcription.tsv` — hand transcription of the official NFL.com Week 10 injury report
  (https://www.nfl.com/injuries/league/2026/reg10, 8 chunks). One row per listed player with an
  injury entry, a non-full practice status, or a game status (205 rows, 14 games).
- `data/w10-rows.json`, `data/w10-team-summary.json` — generated by `build.py`.
- `index.html` — dashboard: games, team position-group exposure, searchable rows.
- `build.py` — validates the TSV (field count, team membership, position codes, duplicates) and writes outputs.

Starter/backup (2nd/3rd-string) replacement fields are blank and flagged UNVERIFIED: no official
depth-chart source was reachable (see advisory/flagged.html F-05 and advisory/questions.html Q-02).
